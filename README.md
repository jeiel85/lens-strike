# 렌즈 스트라이크 · LENS STRIKE

**폰 카메라로 상대를 비추고, 화면을 터치해 쏘는 설치 없는 AR 슈팅 게임**

폰이 곧 총입니다. 카메라 화면 가운데 조준점에 상대를 두고 화면을 터치하면, 폰 안의 사람 인식 AI가 머리·몸통 명중을 판정하고 상대 폰의 HP가 줄어듭니다. 앱 설치 없이 브라우저에서 바로 실행되며, **세로·가로 화면을 모두** 지원합니다.

> **두 가지 버전이 있습니다.**
> - **웹 버전**(이 문서의 대부분): 설치 없이 바로 하는 1대1. 화면에 보이는 사람을 모두 상대로 판정합니다.
> - **AR 앱 버전**(개발 중, [`unity/`](unity/)): 두 폰이 AR 좌표를 공유해 **상대 폰의 실제 위치로** 누구를 맞혔는지 정확히 판정합니다. 지나가던 사람이 맞는 문제가 없고, 마법탄을 몸으로 피할 수 있습니다. 안드로이드(ARCore)부터 지원합니다. 자세한 내용은 [unity/README.md](unity/README.md)에 있습니다.

## 플레이 방법

1. 두 사람이 각자 폰으로 **[jeiel85.github.io/lens-strike](https://jeiel85.github.io/lens-strike/)** 를 엽니다(Chrome 또는 Safari).
2. 닉네임과 캐릭터를 고릅니다.
3. 한 명이 **방 만들기** → 화면의 4자리 코드나 QR을 다른 사람에게 보여 줍니다.
4. 다른 한 명이 코드를 넣고 **참가**(또는 QR을 찍어 바로 입장) → 방장이 **시작**.
5. 상대를 화면 가운데 조준점에 두고 **화면 아무 곳이나 터치**해서 쏩니다. 먼저 **5킬**하면 승리.

혼자 해 보고 싶으면 **혼자 연습**을 누르세요. 화면에 보이는 사람을 훈련 표적으로 삼아 명중 판정을 확인할 수 있습니다.

## 캐릭터와 무기

| 캐릭터 | HP | 무기 | 특징 |
|---|---|---|---|
| **레인저** | 100 | M16형 소총 · K2형 소총 · 샷건 | 3점사 / 연사 / 근거리 산탄. 거리에 맞춰 바꿔 쓴다 |
| **사이버 트루퍼** | 120 | 플라즈마 건 | 누르고 있다가 떼면 충전량만큼 강해진다. 맞은 상대는 0.6초 감전(사격 불가) |
| **마법사** | 100 | 파이어볼 · 워터볼 | 날아가는 마법탄(도착 순간에 조준점 안에 있어야 명중 — 피할 수 있다). 화상 지속 피해 / 젖음(연사 느려짐) |

| 무기 | 피해(몸통) | 머리 배율 | 사격 방식 | 탄창 | 유효/최대 사거리 |
|---|---|---|---|---|---|
| M16형 소총 | 12 | ×2 | 탭 1번에 3점사 | 30 | 25m / 60m |
| K2형 소총 | 8 | ×2 | 누르는 동안 연사 | 30 | 20m / 50m |
| 샷건 | 6 × 8알 | ×1.5 | 단발, 넓은 산탄 원 | 6 | 4m / 12m |
| 플라즈마 건 | 9~45 (충전) | ×1.5 | 누르고 떼기 | 12 | 15m / 40m |
| 파이어볼 | 28 + 화상 12 | ×1.5 | 단발, 0.45초 비행 | 5 | 12m / 25m |
| 워터볼 | 18 + 젖음 | ×1.5 | 단발, 0.38초 비행 | 6 | 12m / 25m |

유효 사거리를 넘으면 최대 사거리까지 피해가 40%로 줄고, 최대 사거리를 넘으면 빗나갑니다. 수치는 [`src/config/weapons.ts`](src/config/weapons.ts) 한 곳에서 조정합니다.

## 명중 판정은 이렇게 합니다

- 폰 안에서 **MediaPipe Pose**가 카메라 프레임마다 사람의 관절 33개를 찾습니다.
- 관절로 머리 원·몸통 사각형·팔다리 캡슐을 만들고, 화면 가운데 조준 원과 겹치는지 봅니다. 머리가 우선입니다.
- 어깨너비·몸통 길이로 **거리를 대략 추정**해 사거리 감쇠에 씁니다.
- "맞혔다"는 보고만 상대에게 보내고, **HP·킬·효과 계산은 방장 폰이** 합니다. 방장은 무기 소유·생존·사거리·연사 속도를 검증합니다.
- 인식 결과가 궁금하면 오른쪽 위 **◎** 버튼으로 인식된 몸 모양과 거리를 켜고 끌 수 있습니다.

## 지원 환경

| 항목 | Android Chrome | iPhone Safari |
|---|---|---|
| 카메라·사람 인식 | ✅ | ✅ |
| 세로 / 가로 화면 | ✅ | ✅ |
| 진동 피드백 | ✅ | ❌ (화면 효과·소리로 대신) |
| 전체화면 | ✅ | ❌ (홈 화면에 추가하면 전체화면) |

- **HTTPS 주소에서만** 카메라가 켜집니다.
- 카카오톡·인스타그램 같은 **앱 안의 브라우저**에서는 카메라가 막힐 수 있습니다. 화면 안내대로 외부 브라우저로 여세요.
- 처음 실행할 때 사람 인식 엔진(압축 기준 약 10MB)을 내려받습니다.
- 두 폰이 서로 다른 네트워크(LTE·와이파이)에 있어도 연결됩니다(WebRTC, 공개 중계 서버 사용).

## 안전 · 개인정보

- **카메라 영상은 기기 밖으로 나가지 않습니다.** 사람 인식은 폰 안에서만 하고, 영상을 저장하거나 전송하지 않습니다. 기기끼리는 닉네임·캐릭터·HP·명중 같은 게임 정보만 주고받습니다.
- 주변을 확인하고 하세요. 도로 근처, 사람이 많은 곳, 화면을 보며 뛰어야 하는 곳은 피하세요.
- 폰을 사람에게 겨누는 놀이라 모르는 사람이 오해할 수 있습니다. 함께 노는 사람끼리만 하세요.

## 알려진 제한

- **1대1 전용**입니다. 지금은 "누구를 맞혔는지"를 구분하지 않아서, 화면에 보이는 사람은 모두 상대로 판정됩니다(지나가던 사람을 맞혀도 상대 HP가 줄어듭니다).
- 거리 추정은 평균 체형과 일반적인 폰 화각을 가정한 대략값입니다.
- 사람 인식 속도는 폰 성능에 따라 다릅니다. 오래 하면 폰이 뜨거워지고 배터리가 빨리 닳습니다.
- 명중 보고는 각자의 폰이 하므로, 클라이언트를 고친 부정행위를 완전히 막을 수는 없습니다(방장이 연사 속도·사거리만 검증).
- 기기 간 연결은 PeerJS 공개 시그널링·중계 서버에 의존합니다. 그 서버가 멈추면 대전을 시작할 수 없습니다(연습 모드는 됩니다).

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 판정·규칙·방아쇠 단위 테스트
npm run build    # dist/ 생성 (GitHub Pages로 자동 배포)
```

폰에서 개발 서버를 열 때는 HTTPS가 필요합니다. Android는 USB/무선 ADB로 포트를 넘기면 `localhost`로 열 수 있습니다.

```bash
adb reverse tcp:5173 tcp:5173
```

### 구조

```
src/
  config/weapons.ts   캐릭터·무기 수치
  game/hit.ts         관절 → 몸 모양, 명중·거리 판정 (순수 함수)
  game/rules.ts       경기 규칙: 피해·효과·킬·부활·검증 (방장에서 실행)
  game/gun.ts         방아쇠: 탄약·재장전·연사·점사·충전
  game/play.ts        한 판의 진행(프레임 루프·입력·HUD)
  vision/             카메라, MediaPipe 사람 인식
  net/                PeerJS 방장/참가자 연결과 메시지 검사
  fx/                 효과음 합성, 화면 이펙트
tests/                Vitest 단위 테스트
```

설계 결정은 [DECISIONS.md](DECISIONS.md), 다음에 할 일은 [BACKLOG.md](BACKLOG.md)에 있습니다.
